# 设计方向

## 一句话

alune 是一个安静、有编辑感的个人数字主页：让作品、文字和个人气质先被看见，让装饰退到第二层。

## 视觉原则

- **克制**：以暖白/深墨和一个受控的强调色建立层级，避免渐变背景、霓虹色和仪表盘式卡片墙。
- **留白**：给标题、段落、图片和分隔线足够呼吸空间；不要为了填满首屏而堆叠模块。
- **有节奏的排版**：标题、摘要、元信息、正文形成稳定层级；长文优先保证行长和行距。
- **真实的材料感**：图片、项目状态和文章日期应反映真实内容，不使用虚构的客户、数据或案例。
- **渐进增强**：核心导航、文章和联系方式在没有 JavaScript 时仍可阅读；脚本只提供筛选、动效等增强。

具体颜色、字体、间距和断点集中在 `src/styles/` 的 tokens 中。组件不要自行发明第二套变量。

## 页面节奏

- 首页先给出一句明确的自我定位，再展示精选 Studio/Journal 内容，最后提供 About 入口。
- Studio 以作品状态、角色和结果为主，避免只展示漂亮截图。
- Journal 先给标题、摘要、日期和主题，再进入正文；详情页保持稳定的阅读列宽。
- About 说清楚现在做什么、如何合作以及哪些事情暂不做。

导航顺序固定为 `Studio`、`Journal`、`About`；移动端可改为折叠菜单，但名称和顺序不变。

## 交互与无障碍

- 使用语义 HTML、可见的键盘焦点和有意义的链接文本。
- 正文与背景保持 WCAG AA 对比度；颜色不是传达状态的唯一方式。
- 图片有准确的 `alt`；装饰图片使用空 `alt`。
- 动效短、轻、可中断；尊重 `prefers-reduced-motion: reduce`。
- 表单或筛选失败时给出文字反馈；不依赖 toast 或 hover 才能理解页面。

## 不要做什么

不要把本站做成后台、SaaS 落地页或动态作品集模板。不要添加未经内容许可的图片、字体或第三方品牌，也不要把尚未实现的 API、CMS 或部署状态写进页面。
