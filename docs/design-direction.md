# 设计方向

## 一句话

alune 是一个安静、有编辑感的个人数字主页：让作品、文字和个人气质先被看见，让装饰退到第二层。

## 视觉原则

- **克制**：使用明亮画布、深墨文字和单一受控强调色建立层级，避免渐变、霓虹和仪表盘式卡片墙。
- **留白**：给标题、段落、图片和分隔线足够呼吸空间，不为填满首屏堆叠模块。
- **排版节奏**：标题、摘要、元信息和正文形成稳定层级；长文优先保证行长与行距。
- **真实材料**：图片、项目状态和日期反映真实内容，不使用虚构客户、数据或案例。
- **渐进增强**：导航、文章和联系方式在没有 JavaScript 时仍可阅读，脚本只提供增强。

颜色、字体、间距和断点以 `src/styles/global.css` 的 tokens 为准，组件不得自行维护第二套变量。当前主导航的名称与顺序以 `src/config/site.ts` 为准。

## 页面节奏

- 首页先给出明确定位，再展示精选 Studio、Journal 和 Now 入口。
- Studio 强调作品状态、角色、结果和真实链接，不只展示截图。
- Journal 先呈现标题、摘要、日期和主题，详情页保持稳定阅读列宽。
- About 说明个人叙事、工作方式和联系方式；Now 记录当前阶段。

## 交互与无障碍

- 使用语义 HTML、可见键盘焦点和有意义的链接文本。
- 正文与背景至少满足 WCAG AA；颜色不是表达状态的唯一方式。
- 内容图片使用准确 `alt`，装饰图片使用空 `alt`。
- 动效短、轻、可中断，并尊重 `prefers-reduced-motion`。
- 核心信息不得依赖 hover、toast 或仅视觉状态才能理解。

## 非目标

本站不是后台、SaaS 落地页或通用作品集模板。不要为了展示感引入未经授权的图片、字体、第三方品牌或虚构内容；具体视觉方向可以在真实内容形成后继续迭代。
