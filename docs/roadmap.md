# 路线图

路线图只记录已经决定的阶段，不把愿望清单当作承诺。

## 当前：工程基础完成，内容待补

- Astro 单包项目能够安装、开发、构建和静态预览。
- 首页、作品、文章、关于、近况、主题、RSS 与基础 SEO 已建立。
- 作品、文章、固定页面使用 schema 校验的仓库内容和可复制模板。
- 文档、lint、格式、类型、单元测试、构建与 Playwright 构成质量门。
- 代码和原创内容、品牌素材使用不同许可证边界。
- 站点仍使用占位域名、作者资料和回退文案，尚未达到正式发布条件。

## 下一步：真实内容与品牌细节

1. 补齐真实作者资料、联系方式，以及至少一条作品和文章内容。
2. 用真实内容校验首页、列表、详情、关于页与分享卡片的阅读节奏。
3. 在真实设备上复核键盘、对比度、减少动效和图片加载表现。
4. 在内容稳定后继续设计视觉细节，不提前锁定尚未验证的品牌文案。

## 长期扩展

- 新作品、小工具和外部网页优先作为作品（`studio`）条目展示，通过明确的 launch/source 链接连接。
- 只有工具需要独立运行时、数据或权限时，才单独评估应用边界；个人主页继续保持静态和低维护。
- 远程内容编辑、表单、后端或 CMS 必须先明确隐私、存储、成本和维护责任，再单独立项。

## 部署决策门

部署方案当前延期。开始部署前，需要确定域名、托管平台、中国大陆三网直连验收方式、缓存、回滚和品牌资产授权，再新增 deployment workflow。

在这些决定完成前，后端、数据库、登录、后台管理、队列和企业业务流都不是当前范围。
